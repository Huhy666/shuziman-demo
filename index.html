Capabilities

两种模式，覆盖两类口播场景

面向商家带货与个人口播两类需求，按模式组织输入、校验和生成分支。

🛍️

带货模式

人物图 + 商品图 + 商品标题/介绍，先生成商业口播场景图，再由 LLM 生成 80 字以内卖点文案，最后合成口播视频。

人物 + 商品卖点文案场景合成
🎙️

自定义模式

人物图 + 完整口播文案，跳过商品图与前置图合成，直接完成 TTS 配音与人物口播视频生成，链路更短。

完整文案快速出片音色可控
🔀

双路径与多来源

同时支持 ComfyUI / RunningHub 工作流与直连参考生视频 API；前置图服务和口播视频服务可分别选择来源。

WorkflowDirect API可切换
Workflow

从素材到成片，六个环节

模块负责业务编排与交互，LLM、TTS、媒体生成、历史记录由平台公共服务提供。

01素材上传人物图 / 商品图
02前置图生成人物 + 商品场景
03卖点文案用户输入 / LLM 生成
04TTS 配音音色 · 语速 · 参考音频
05口播合成场景图 + 旁白音频
06成片下载final.mp4
Engineering

把不稳定的模型能力，编排成稳定的生产链路

除了“能生成”，模块还处理来源选择、参数差异、失败分支和产物留存。

01

工作流 + 直连 API 双路径

工作流适合定制画面与本地部署；直连 API 适合标准化口播与少运维场景。模块统一两套输入输出，业务层不混用参数。

02

RunningHub / selfhost / API 多来源

前置图与口播视频可分别选择来源，动态检查 API Key、ComfyUI 地址与工作流文件，减少无效配置。

03

任务隔离与异常处理

独立任务目录、生成前参数校验、工作流状态判断、视频 URL 提取与下载超时控制，错误定位到具体阶段。

04

历史留存与跨模块协作

生成后写入模式、商品信息、素材与 TTS 参数；与平台 TTS、媒体生成、历史记录服务按接口契约联调。
